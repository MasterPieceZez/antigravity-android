# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in **Antigravity for Android** (`MasterPieceZez/antigravity-android`), please report it privately via GitHub Security Advisories:

https://github.com/MasterPieceZez/antigravity-android/security/advisories/new

Please include reproduction steps, affected APK version, Android version, and any relevant logs (with tokens redacted). Do not open a public issue for unpatched security vulnerabilities.

For vulnerabilities in the upstream Termux components, see https://termux.dev/security.
